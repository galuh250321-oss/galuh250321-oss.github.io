# Portofolio Galuh Sutisna

Website portofolio dan tiga demo yang bisa dicoba langsung:

- `umkm/`: landing page UMKM (toko mochi fiktif) dengan pemesanan lewat WhatsApp
- `dashboard/`: dashboard penjualan yang bisa disambungkan ke Google Sheets
- `iot/`: monitoring kualitas air tambak dengan data sensor simulasi

Semua halaman berupa HTML statis tanpa server, dihosting di GitHub Pages.
Nama usaha dan data di dalam demo adalah fiktif.
